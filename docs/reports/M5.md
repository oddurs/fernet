# Milestone 5 (v0.5), more strata: report

## What shipped

- **Markdown** (read/write): headings as nested directories, a `body` file per
  section, checked body writes, new sections, removals.
- **CSV** (read/write): rows by index, fields by header, minimal re-quoting, new
  rows, row removal.
- **SQLite** (read-only): tables → rows by primary key (or `rowid`, or
  position) → columns, with blobs as raw bytes.
- **zip and tar** (read-only): the archive's tree with raw-byte files, capped at
  256 MiB unpacked.
- **Shell completions** for bash, zsh and fish, dynamic through the resolver:
  keys after `#/`; listing, specs, days and marks after `@`.
- **`fernet log --size`** (from M2) plus a configurable warning
  (`store_warn_bytes`) on `log`, `watch` and `mount`.

## Acceptance criteria

| Criterion | Evidence |
| --- | --- |
| Each new driver has fuzz targets | `markdown_parse`, `csv_parse`, `sqlite_parse`, `zip_parse`, `tar_parse` (in the CI matrix). The writable ones also check that rewriting a value with its own text reparses to the same value |
| Golden tests | `crates/fernet-formats/tests/strata.rs`: a README outline (fenced code, indented code, setext, duplicates); CSV compared with the `csv` crate (quotes, embedded newlines, CRLF); SQLite and archive unit tests build real databases and archives with `rusqlite`, `zip` and `tar` |
| Splice property test where writable | `strata.rs::{markdown,csv}_splice_invariant`, 512 cases each |

Through the resolver: `tests/tests/strata_paths.rs` reads and writes Markdown and
CSV with `#` paths.

## Bugs found

The new fuzz targets found three crashes within a minute:
- A Markdown heading inside a list can extend past the next heading. Spans are
  now clamped.
- A byte-order mark before a heading made a backwards range. The driver now
  parses after the BOM and shifts ranges back.
- The shared fuzz checker assumed parsed input is UTF-8, which isn't true for
  archives.

## Deviations

- CSV rows aren't keyed by a configured column yet (DECISIONS 44).
- Only uncompressed tar (DECISIONS 45).
- Completion scripts are hand-written, not `clap_complete` (DECISIONS 46).
